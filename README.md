# Catherina

**适用于 Mengka NT 的 QQ 助手，全部功能免费。**

把群管理、消息回复、菜单、群发和定时任务放在一个管理页面里。菜单正文、自定义菜单、功能菜单与额外管理 QQ 由所有账号共用；自动功能、问答和任务按 QQ 保存。

Catherina 支持两种运行方式：导入萌卡 NT 时使用原生 IPC；独立运行时可通过 WebSocket 连接。支持 Windows x64、Linux x64 和 Linux ARM64。

[下载安装包](https://github.com/Jay1023CN/Mengka-NT-plugins/releases) · [反馈问题](https://github.com/Jay1023CN/Mengka-NT-plugins/issues)

## 可以做什么

| 分类 | 功能 |
| --- | --- |
| 消息与群发 | 分别向指定群或好友发送消息；可预览收件对象、确认后发送，并设置循环或每天定时发送 |
| 菜单与回复 | 自定义菜单正文、触发词和回复内容，多行前后缀，问答库，触发人员名单 |
| 群聊管理 | 成员禁言、全体禁言、踢人、群公告、成员查询、专属头衔、群打卡 |
| 聊天互动 | 艾特回复、戳一戳回复、消息表情回应、名片点赞、随机回话、私聊互动天数与续火提醒 |
| 消息辅助 | 撤回消息文本还原、闪照保存、消息与事件记录、好友及入群申请处理、红包领取 |
| QQ 与空间 | 好友备注、个性签名、账号状态、空间动态点赞评论、定时说说、免费等级任务查询与执行 |
| 实用工具 | 网易云点歌、随机字母、字数统计、文本统计与反转、全角与半角转换 |
| 通知与反馈 | 上线通知、自定义通知对象与内容、转交问题反馈、插件公告与版本更新入口 |

功能可以按账号单独开关，聊天指令的触发词也可以修改。群管理操作使用当前 QQ 的群权限；撤回还原只处理插件已经收到并缓存的消息文本。

## 下载与启动

先准备好正在运行的 [Mengka NT](https://github.com/Carlor-Official/Mengka-NT)，再下载对应系统的 Catherina 安装包。

| 系统 | 选择的文件 | 启动程序 |
| --- | --- | --- |
| Windows x64 | 文件名包含 `windows-amd64` | `Catherina.exe` |
| Linux x64 | 文件名包含 `linux-amd64` | `Catherina` |
| Linux ARM64 | 文件名包含 `linux-arm64` | `Catherina` |

把安装包解压到一个可写的文件夹。ZIP 用于下载安装，运行时使用解压后的程序。

已有用户更新时，先退出程序，再替换对应的可执行文件；保留原来的数据目录。

### Windows

双击 `Catherina.exe`，浏览器会打开管理页面。程序窗口需要保持运行。

### Linux

进入解压后的目录执行：

```sh
chmod +x Catherina
./Catherina
```

在运行程序的电脑上打开 **http://127.0.0.1:18096**。

管理页面已经内置，无需另外安装 Go、Node.js 或 WebView2。使用管理页面、下载安装包均不需要登录 GitHub。

## 首次连接

1. 萌卡 NT 需为 2.5.4 或更新版本。将成品包导入“插件 → 插件导入”，确认权限后启动。原生 IPC 不需要开放插件端口，也不需要填写服务令牌。
2. 从萌卡插件卡片打开 Catherina 管理页面，首次进入时设置一个至少 8 位的管理密码。
3. 若要独立运行 Catherina，在萌卡“插件对接”中启用正向 WebSocket，创建服务令牌，并在“连接与更新”填写地址和令牌。
4. 从左侧选择要管理的 QQ，本人直接给自己发送指令即可使用，无需填写额外管理 QQ。
5. 默认即可使用本人指令。需要自动回复或定时发送时，再配置发送名单和自动任务。

连接后可以刷新 QQ 列表。切换 QQ 后，页面显示的是该账号自己的配置；同一 QQ 使用不同协议时也分别保存。

## 管理页面怎么用

| 页面 | 用途 |
| --- | --- |
| 总览 | 查看当前账号、功能状态和插件公告 |
| 功能与指令 | 开关功能，搜索功能，修改指令触发词，设置触发人员 |
| 共用菜单 | 编辑菜单正文、前后缀、自定义菜单和各项功能的回复内容 |
| 问答与白名单 | 添加问答；从当前 QQ 的群和好友列表里选择群发对象，也可手动输入号码 |
| 自动任务 | 添加、编辑、暂停或删除循环群发、定时群发、定时说说 |
| 全局设置 | 可选的额外主人、配置作用范围说明 |
| 账号设置 | 回复文案、上线通知和按群单独开关 |
| 连接与更新 | 管理萌卡连接，查看版本信息 |
| 接口调试 | 发送 HTTP 请求并查看返回内容 |
| 监控记录 | 查看当前账号命中的监控消息，可一键清空；记录保留 7 天 |

功能开关点击后保存。菜单在弹窗内直接保存；保存失败时保留输入并显示原因。账号设置等页面编辑后点击“保存修改”，也可以按 **Ctrl+S**。

### 从总菜单找到指令

发送“菜单”或“总菜单”查看按四字宽度对齐的功能目录，再发送功能名称进入对应子菜单。子菜单按当前账号启用的指令生成，旧分类入口仍可使用。

例如，发送“群发菜单”查看群发指令；问答可用“添加精准问xxx答xxx”或“添加模糊问xxx答xxx”。群发消息会跳过群和好友排除名单。

网页“共用菜单”直接显示当前 QQ 实际收到的回复，包含已修改的触发词和共用前后缀。修改内置功能菜单正文后，发送对应菜单即可生效；与内置菜单重名的自定义触发词会提示修改。

### 配置一条自定义菜单

进入“共用菜单”，点击“添加菜单”，填写触发词和实际回复内容。可以设置仅好友触发，或允许好友和群聊触发；需要限制使用人员时，填写触发人员 QQ。

菜单正文、前缀和后缀都可以直接换行，也可以插入变量。例如：

```text
你好，【发送者QQ】
这里是【插件名字】
当前时间：【现行时间】
```

| 变量 | 含义 |
| --- | --- |
| `【发送者QQ】` | 发送这条消息的人 |
| `【框架QQ】` | 当前机器人 QQ |
| `【群号】` | 当前群号，私聊时为空 |
| `【插件名字】`、`【插件版本】` | 插件名称与版本 |
| `【现行时间】` | 当前日期和时间 |
| `【10位时间戳】`、`【13位时间戳】` | 秒级、毫秒级时间戳 |
| `【换行符】`、`【空格】` | 插入换行或空格 |

### 配置群发和定时任务

先在“问答与白名单”分别选择接收群消息的群、接收私聊消息的好友。点“从当前 QQ 选择”可按名称搜索萌卡返回的联系人，不需要记号码；旧版群发名单会继续作为群聊收件对象保留。然后到“自动任务”选择群、好友或两者，填写内容及时间，保存并启用。

聊天指令分为“群发群”和“群发好友”。先发出预览，确认对象、数量和内容后再回复“确认发送”，两分钟内有效；发送前可以回复“取消发送”放弃这次预览。循环和定时任务按所选对象发送；每天定时任务使用程序所在电脑的本地时间，任务可以单独暂停，保存后重启仍在。任务卡片显示下次执行与最近结果，编辑内容会保留执行历史；恢复任务会重新安排未来的执行时间。

## 版本与自动更新

从 **1.0.0** 开始使用主版本.次版本.修订号，每次正式发布递增版本。日期版用户首次切换到 1.0.x 需要重新导入安装包，账号数据保留。旧日期版界面可能把 2026 开头的版本号误判为比 1.0.x 更新；请以新版安装包版本为准。

独立运行默认在后台自动下载安装新版，启动后检查一次，此后每小时检查。萌卡托管模式可在管理页登录当前框架后在线更新，由插件下载并校验安装包，再交给框架安装。

接口调试支持当前 QQ 的萌卡接口名称和 JSON 参数，也支持带自定义请求头的 HTTP 请求，可查看耗时、响应头及格式化结果。调试修改类接口会实际执行对应操作。

“共用菜单”中直接展示实际正文。“菜单”和“总菜单”回复同一份共用内容，自定义菜单、功能菜单回复和前后缀也由所有 QQ 共用。默认菜单会自动生成，不需要先猜触发词或填写模板。“搜索命令 关键词”可以查询具体用法。

## 数据保存

账号配置、菜单、问答和任务保存在本机。默认数据目录：

- Windows：`%APPDATA%\Catherina-Mengka`
- Linux：`~/.config/Catherina-Mengka`；设置了 `XDG_CONFIG_HOME` 时使用对应目录。

更换电脑前，先退出程序，再备份整个数据目录。

## GitHub 连接不稳定时

程序启动后检查新版，此后每小时检查一次。下载失败或文件校验不通过时会保留当前版本，之后可以重新检查。

在“连接与更新”点击“立即在线更新”即可开始。萌卡托管运行需要当前萌卡的管理员登录会话有效；页面会显示下载和安装进度。

需要手动更新时，从本页的公开发布页获取对应平台的 ZIP，再到萌卡“插件导入”安装，保留原来的数据目录。

## 常见问题

**连不上萌卡或没有 QQ 列表？**

确认萌卡已经运行，QQ 已登录，正向 WebSocket 已开启。填写的是 WebSocket 地址，而非萌卡网页地址；同时检查服务令牌和事件权限，连接后刷新 QQ 列表。

**指令没有回复？**

先确认左侧选中了正确的 QQ，再检查功能开关和触发词。群发需要分别选择接收群或好友；好友消息只会发送给当前 QQ 的好友，群消息只会发送到当前 QQ 所在的群。群管理需要当前 QQ 具备相应权限。

**Linux 程序运行在远程电脑上，怎么打开管理页面？**

在自己的电脑建立 SSH 端口转发，把 `user@host` 改成远程电脑的登录账号和地址：

```sh
ssh -L 18096:127.0.0.1:18096 user@host
```

保持连接，再在自己的浏览器打开 **http://127.0.0.1:18096**。

**遇到问题怎么反馈？**

在 [Issues](https://github.com/Jay1023CN/Mengka-NT-plugins/issues) 写明插件版本、系统、出问题的操作和截图。请遮住截图中的管理密码与服务令牌。

### 本人与其他人的指令权限

登录 QQ 本人默认拥有指令权限。只给自己使用时，不需要配置额外管理 QQ 或名单。

“功能与指令”中可以按功能设置其他人可用的范围：不额外开放、允许所有人、只允许指定 QQ。额外管理 QQ 仍可管理账号；停用单条指令后，该指令不响应。“菜单”和“总菜单”保留为公共查询入口。

“账号设置”中的群级开关可以逐项选择继承账号、单独开启或单独关闭，不需要填写 JSON。

## 在线更新与共用菜单

“连接与更新”中点击“立即在线更新”。独立运行会自动安装并重启；萌卡托管运行会让你登录当前萌卡的管理员账号，然后自动下载、校验并提交给框架升级，不需要保存 ZIP 后再上传。图形验证码由当前萌卡提供；密码不保存，登录会话只保留在当前插件进程内。新版有权限变更时，页面会列出变更并等待确认。后台每小时检查一次，有效管理员会话下可自动提交新版；重启或会话到期后需要重新登录。

菜单页直接显示实际正文，“菜单”和“总菜单”共用同一份内容。自定义菜单、功能菜单回复和前后缀也由所有登录 QQ 共用。本人手动指令不依赖自动功能开关，明确停用的指令除外；自动功能支持批量开启或关闭。

“给别人安装”提供公开发布页，对方将插件安装在自己的萌卡或机器上，使用自己的入口和登录会话。

## 从源码构建

需要 Go 1.26 或更新版本。克隆仓库后，在项目目录运行：

```sh
go build ./cmd/catherina
```

运行单元测试：

```sh
go test ./...
```

源码构建不包含发布签名密钥。发布版只接受签名校验通过的更新清单。

1.0.2 等旧版未包含托管在线更新入口，需要先导入支持在线更新的版本一次。
