# Catherina

适用于 Mengka NT 的 QQ 助手，支持 Windows x64、Linux x64 和 Linux ARM64。

## 下载与启动

从 [Releases](https://github.com/Jay1023CN/Mengka-NT-plugins/releases) 下载对应系统的安装包，解压后运行 `Catherina.exe`（Windows）或 `Catherina`（Linux）。ZIP 只用于分发，运行时不需要保留。

管理页面默认地址为 `http://127.0.0.1:18096`。首次打开设置管理密码，再填写萌卡的 WebSocket 地址和服务令牌。

程序已内置管理页面和 SQLite，无需安装 Go、Node.js 或 WebView2。每个 QQ 的配置独立保存。

## 功能

- 功能开关与触发指令管理。
- 多行菜单、自定义回复和变量。
- 问答、群发白名单、自动任务与上线通知。
- 插件公告和自动更新。

全部功能免费。
